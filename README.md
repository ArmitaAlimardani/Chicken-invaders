# Requirements

- Java JDK 21
- SQLite JDBC Driver
  

# How to Run

1. Open the project in IntelliJ IDEA.
2. Make sure the SQLite JDBC library is added to the project.
3. Run the `GameMain` class.

# Controls

 (← / →) = Move player 
 Space = Shoot 
 Enter = Restart after victory 
 Space = Restart after defeat 



# Database

The project uses **SQLite**.
Database file: game.db
Tables:
1) users : Stores user accounts and current sound settings.
2) game_records : Stores the final score, last level, timestamp, and sound settings for every finished game.

The database is automatically created and initialized when the application starts.
